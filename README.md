# 🐱 Cat Feeding Calculator

A simple, elegant web-based calculator that helps cat owners determine the ideal daily food portions for their feline companions.

**Live Demo:** [https://xiaoyingcc.github.io/Cat-feeding-calculator/](https://xiaoyingcc.github.io/Cat-feeding-calculator/)

## Features

- 🧮 Calculate daily wet & dry food portions based on weight and life stage
- 🐾 Intuitive slider to adjust wet/dry food ratio
- 💾 Save multiple cat profiles with localStorage persistence
- 📚 Custom food library — save your cat's favorite brands
- 🌐 Bilingual support (English / 中文)
- 📱 Fully responsive design for mobile and desktop
- ♿ Accessible color palette with clear focus states

## Tech Stack

- **HTML5** / **CSS3** / **Vanilla JavaScript**
- No frameworks or build tools required
- Deployed via **GitHub Pages**

## Getting Started

### Prerequisites

Any modern web browser (Chrome, Firefox, Safari, Edge).

### Run Locally

```bash
git clone https://github.com/xiaoyingcc/Cat-feeding-calculator.git
cd Cat-feeding-calculator
# Open directly
open index.html
# Or serve with a local server
python3 -m http.server 8080
```

Then visit `http://localhost:8080` in your browser.

## Usage

1. **Create a cat profile** — Enter your cat's name, weight, and life stage, then click "Save this Cutie".
2. **Set up food info** — Enter the calorie density (kcal/g) of your cat's wet and dry food, or select from saved foods.
3. **Adjust the ratio** — Use the paw slider to set your preferred wet/dry food split.
4. **Read the results** — The calculator instantly shows how many grams of each food to serve daily.
